*Want to install Decky Loader?* There is a `ujust` command for that: `ujust setup-decky install`
*Installed a game with Lutris?* Right click on it and `Create steam shortcut` to play it in 󰓓 Steam game mode.
*Games missing artwork?* The `SteamGridDB` plugin for Decky Loader makes it easy to add the missing art~[More info](https://github.com/SteamGridDB/decky-steamgriddb)
*Not sure which games run on Linux?* The `ProtonDB Badges` plugin for Decky Loader adds community compatibility badges to your whole 󰓓 Steam library~[More info](https://github.com/OMGDuke/protondb-decky)
ProtonPlus installs and updates custom Proton builds. Proton-GE is the recommended one for problematic games.
*Playing on a handheld with few buttons?* 󰓓 Steam game mode supports touch gestures to slide the menus out, thanks to [ChimeraOS](https://chimeraos.org/).
